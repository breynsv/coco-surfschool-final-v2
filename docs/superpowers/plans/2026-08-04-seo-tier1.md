# SEO/GEO Tier 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land every SEO/GEO fix that needs no decision from the site owner — image weight, schema completeness, heading hierarchy, entity signals, internal linking, dead code.

**Architecture:** `build.mjs` generates 50 static pages from `content/{fr,en,nl,de,es}.mjs`. All fixes go in the generator or the content files; generated HTML is never hand-edited. `PROD=1` gates production output. Tests are bare `node --test`.

**Tech Stack:** Node v25 ESM (no dependencies, no `package.json`), built-in `node:test`, `sips` for image conversion.

Source: two parallel audits (technical SEO + GEO/local), findings independently verified 2026-08-04.

## Global Constraints

- **No new runtime dependencies.** No `package.json`. `node:` built-ins only.
- **Never hand-edit generated HTML** in `fr/ en/ nl/ de/ es/`. Fix the generator or content files, then rebuild.
- **Canonical host is `https://www.coco-surfschool.com`** (`SITE` in build.mjs). Do not change it.
- **Default build behaviour must not change.** Bare `node build.mjs` stays a noindexed preview. Only `PROD=1` is committable.
- **Never touch** `booking-preview/`, `vragenlijst/`, `rapport/`.
- **Never invent facts.** Do not add review counts, opening hours, coordinates, or certifications that are not already present in the repo. Those are deferred pending the owner.
- Tests run as **bare** `node --test`. Never `node --test test/` — Node v25 mis-parses a directory arg.
- Every task ends with `PROD=1 node build.mjs` and commits the regenerated output.

### Task 1: Cut image weight from 11.3 MB to under 2 MB

Five PNGs average ~2 MB each and several are the LCP element with `fetchpriority="high"`.

**Files:**

**Interfaces:**

scrapers still mishandle WebP `og:image`. JPEG q82 measured 85% smaller on a sample.

**Do NOT convert** `ee16c3_71361371647c417f89cde7e315ac662c.png` — that is the logo/favicon

confirm it has no alpha channel; if unsure, leave it.

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { execFileSync } from 'node:child_process';
import { mkdtemp, readFile, readdir, stat } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';

const REPO = dirname(dirname(fileURLToPath(import.meta.url)));

async function builtTo(extraEnv = {}) {
  const out = await mkdtemp(join(tmpdir(), 'coco-seo-'));
  execFileSync(process.execPath, [join(REPO, 'build.mjs')], {
    env: { ...process.env, COCO_OUT: out, ...extraEnv },
    stdio: 'pipe',
  });
  return out;
}

/** Every assets/images/... referenced by any generated page, deduped. */
async function referencedImages(out) {
  const found = new Set();
  const walk = async (dir) => {
    for (const e of await readdir(dir, { withFileTypes: true })) {
      const p = join(dir, e.name);
      if (e.isDirectory()) await walk(p);
      else if (e.name.endsWith('.html')) {
        const html = await readFile(p, 'utf8');
        for (const m of html.matchAll(/assets\/images\/([A-Za-z0-9._-]+)/g)) found.add(m[1]);
      }
    }
  };
  for (const lang of ['fr', 'en', 'nl', 'de', 'es']) await walk(join(out, lang));
  return [...found];
}

test('every referenced image exists on disk', async () => {
  const out = await builtTo({ PROD: '1' });
  const missing = [];
  for (const name of await referencedImages(out)) {
    try { await stat(join(REPO, 'assets/images', name)); }
    catch { missing.push(name); }
  }
  assert.deepEqual(missing, [], `referenced but absent: ${missing.join(', ')}`);
});

test('no referenced image exceeds 600 KB', async () => {
  const out = await builtTo({ PROD: '1' });
  const heavy = [];
  for (const name of await referencedImages(out)) {
    try {
      const s = await stat(join(REPO, 'assets/images', name));
      if (s.size > 600 * 1024) heavy.push(`${name} (${(s.size / 1048576).toFixed(2)} MB)`);
    } catch { /* covered by the previous test */ }
  }
  assert.deepEqual(heavy, [], `oversized images: ${heavy.join(', ')}`);
});

test('no unreferenced images are shipped', async () => {
  const out = await builtTo({ PROD: '1' });
  const used = new Set(await referencedImages(out));
  // The favicon is referenced from the root index.html and 404.html, outside the language dirs.
  used.add('ee16c3_71361371647c417f89cde7e315ac662c.png');
  const orphans = (await readdir(join(REPO, 'assets/images'))).filter(f => !used.has(f));
  assert.deepEqual(orphans, [], `unreferenced images still in repo: ${orphans.length}`);
});
```

- [ ] **Step 1: Write the failing test**

```js
test('no page skips a heading level', async () => {
  const out = await builtTo({ PROD: '1' });
  const bad = [];
  const walk = async (dir) => {
    for (const e of await readdir(dir, { withFileTypes: true })) {
      const p = join(dir, e.name);
      if (e.isDirectory()) await walk(p);
      else if (e.name === 'index.html') {
        const html = await readFile(p, 'utf8');
        const levels = [...html.matchAll(/<h([1-6])[ >]/g)].map(m => Number(m[1]));
        for (let i = 1; i < levels.length; i++) {
          if (levels[i] - levels[i - 1] > 1) {
            bad.push(`${p.replace(out, '')}: h${levels[i - 1]} -> h${levels[i]}`);
            break;
          }
        }
      }
    }
  };
  for (const lang of ['fr', 'en', 'nl', 'de', 'es']) await walk(join(out, lang));
  assert.deepEqual(bad, [], `heading level skipped:\n${bad.join('\n')}`);
});
```
